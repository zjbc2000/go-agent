# AI标书撰写平台 - 项目架构说明

## 项目概述

本项目是一个基于Python FastAPI框架的AI标书撰写平台后端服务,支持Docker部署,使用GaussDB数据库。

## 技术栈

- **编程语言**: Python 3.10+
- **Web框架**: FastAPI 0.104+
- **ORM**: SQLAlchemy 2.0+
- **数据库**: GaussDB Kernel 505.2.1.SPC0800 (兼容PostgreSQL)
- **任务队列**: Celery + Redis
- **部署方式**: Docker + Docker Compose

## 核心模块说明

### 1. 配置管理 (app/config/)

- **settings.py**: 使用pydantic-settings管理所有配置项,从.env文件读取环境变量
- **database.py**: GaussDB数据库连接配置,使用SQLAlchemy连接池

### 2. API层 (app/api/)

- **分层设计**: API v1版本化管理,便于后续版本迭代
- **依赖注入**: 统一的用户认证和数据库会话管理
- **四个核心模块**:
  - AI标书检查: 招投标文件上传、解析、检查
  - AI标书写作: 项目解读、目录生成、正文编写
  - 图片库: 图片上传、管理、标签管理
  - 知识库: 文件上传、解析、管理

### 3. 数据库访问层 (app/config/database.py)

- **JDBC连接**: 使用jaydebeapi连接GaussDB数据库
- **连接池**: 线程安全的数据库连接管理
- **会话管理**: DatabaseSession类封装数据库操作
- **查询封装**: DBCursor和DBRow类提供便捷的数据访问接口

### 4. Schema层 (app/schemas/)

- **请求验证**: 使用Pydantic进行请求参数验证
- **响应格式**: 统一的响应格式(code, message, data)
- **类型安全**: 完整的类型注解,支持IDE智能提示

### 5. 业务逻辑层 (app/services/)

- **业务封装**: 将复杂业务逻辑封装在Service层
- **依赖注入**: 通过构造函数注入数据库会话
- **事务管理**: 统一的事务提交和回滚机制

### 6. 核心功能 (app/core/)

- **认证授权**: JWT Token认证,支持Token过期
- **异常处理**: 统一的异常类和错误响应格式
- **中间件**: 请求日志记录、性能监控

### 7. 工具类 (app/utils/)

- **文件处理**: 文件上传、保存、删除、大小验证
- **文件服务**: 封装外部文件服务API调用（OSS-like服务）
- **AI客户端**: 封装AI服务调用,支持重试机制

## 环境变量配置

所有配置都通过.env文件管理,主要包括:

- **应用配置**: 应用名称、版本、环境、调试模式
- **服务器配置**: 主机、端口、工作进程数
- **数据库配置**: GaussDB连接信息、连接池大小
- **Redis配置**: Redis连接信息
- **文件存储**: 上传目录、文件大小限制、允许格式
- **AI服务**: AI服务URL、超时时间、重试次数
- **认证配置**: 密钥、Token过期时间
- **日志配置**: 日志级别、日志文件路径
- **CORS配置**: 允许的源、方法、头部

## 部署方式

### Docker部署

1. **构建镜像**:
```bash
docker build -t ai-bidding-writer:latest .
```

2. **运行容器**:
```bash
docker run -d -p 8000:8000 --env-file .env ai-bidding-writer:latest
```

3. **Docker Compose**:
```bash
docker-compose up -d
```

### 服务组件

- **app**: FastAPI应用服务
- **gaussdb**: GaussDB数据库服务
- **redis**: Redis缓存服务
- **celery-worker**: Celery异步任务工作进程

## 注意事项

1. **数据库连接**: 使用JDBC连接GaussDB，需要配置JDBC驱动路径
2. **数据库兼容性**: GaussDB兼容PostgreSQL，使用jaydebeapi驱动
3. **文件上传**: 大文件上传通过外部文件服务处理（OSS-like服务）
4. **异步任务**: 文件解析、AI生成等耗时操作使用Celery异步处理
5. **日志管理**: 使用loguru进行日志记录，支持日志轮转
6. **性能优化**: 使用Redis缓存、数据库连接池、异步IO
